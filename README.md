# SPARSH - Department of Agriculture, Himachal Pradesh

An Android application to provide comprehensive information about various schemes offered by the Department of Agriculture, Himachal Pradesh.

## Description
**SPARSH** is a native Android application that allows users to explore and access detailed information about government schemes provided by the Department of Agriculture, Himachal Pradesh. The app features an intuitive interface to browse, search, and filter schemes dynamically across different sectors.

## Features
* **Scheme Listing**: View a comprehensive list of all agricultural and horticultural schemes.
* **Search Functionality**: Instantly search for specific schemes by name in real-time.
* **Categorized Filtering**: Filter schemes based on categories such as Financial, Educational, Agriculture, etc.
* **Detailed Information**: View complete guidelines for each scheme, including:
  * Scheme overview & description
  * Eligibility criteria
  * Step-by-step application instructions (Online & Offline)
  * Selection process & subsidy details
  * Required documents & additional info
* **Video Guides**: Watch embedded YouTube video tutorials directly inside the app without external redirections.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
* **Android Studio** (Hedgehog / Iguana or later recommended)
* **Android SDK** (API Level 24 to 34)
* **Gradle** (v8.6+)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mohamadzuheer6-gif/SPARSH.git
   ```
2. Open the project in **Android Studio**.
3. Allow Gradle to sync and build project dependencies.
4. Run the application on an Android Emulator or physical device connected via USB/Wi-Fi.
