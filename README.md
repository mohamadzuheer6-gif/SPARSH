# SPARSH - Himachal Pradesh State Government Schemes Portal

An Android application designed to provide comprehensive information about government schemes offered across key state departments in Himachal Pradesh.

## Description
**SPARSH** is a native Android application that serves as a multi-sector information portal for citizens and farmers in Himachal Pradesh to explore government schemes, eligibility criteria, and application processes. 

The app features a central department dashboard grid covering **6 major state sectors**:
1. **Agriculture (Kheti)** - Fully implemented with active state agricultural schemes & subsidies
2. **Horticulture (Bagwani)** - Multi-sector expansion module
3. **Tourism (Paryatan)** - Multi-sector expansion module
4. **Industries (Udyog)** - Multi-sector expansion module
5. **Expenditure (Vyay)** - Multi-sector expansion module
6. **Telecom (Dur-Sanchar)** - Multi-sector expansion module

## Features
* **Multi-Sector Dashboard Grid**: Select from 6 major state departments on the main screen.
* **Scheme Listing**: Comprehensive list of active government schemes with category tags.
* **Search Functionality**: Instantly search for specific schemes by name in real-time.
* **Categorized Filtering**: Filter schemes based on categories such as Financial, Educational, Agriculture, etc.
* **Detailed Information**: Complete guidelines for each scheme, including:
  * Scheme overview & description
  * Eligibility criteria
  * Step-by-step application instructions (Online & Offline)
  * Selection process & subsidy details
  * Required documents & additional info
* **Video Guides**: Embedded YouTube video tutorials directly inside the app without external redirections.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
* **Android Studio** (Hedgehog / Iguana or later recommended)
* **Android SDK** (API Level 24 to 34)
* **Gradle** (v8.6+)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mohamadzuheer6-gif/SPARSH.git
   ```
2. Open the project in **Android Studio**.
3. Allow Gradle to sync and build project dependencies.
4. Run the application on an Android Emulator or physical device connected via USB/Wi-Fi.
